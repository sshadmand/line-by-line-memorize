# Line by Line · Memorize

A tiny, self-contained presentation practice page. Paste your text with line breaks, then redact trailing words from each line one step at a time as you memorize.

## Use it

Open `index.html` in a browser. There is no build step or dependency.

- Adjust the range or use **+ 1** / **− 1** to redact or reveal trailing words on each line.
- Hold **Reveal answers** to peek at the redacted words.
- Use **Focus mode** to hide the editor while practicing.

GitHub Pages can host this page directly from the repository.
