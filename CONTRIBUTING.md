# Contributing

Thanks for considering an improvement to Line by Line. Upstream pull requests are the best way to help improve the original project and are very welcome.

## Propose a change

- For a larger change, open an issue first so we can discuss the approach.
- For a small fix, open a pull request with a clear summary and the reason for the change.
- Keep the page self-contained unless a dependency is needed to solve the problem.
- Describe how you checked the change and include screenshots for visual changes when useful.

There is no requirement to contribute changes upstream in order to use, share, or fork this project. Contributions are licensed under the GNU Affero General Public License, version 3 or any later version, as described in [LICENSE](LICENSE).
